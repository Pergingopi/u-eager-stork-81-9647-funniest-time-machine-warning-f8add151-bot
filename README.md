A deterministic program that writes one line — the funniest warning label for a time machine — to `/output/entry.txt`. The label: the warranty covers only one of you, so if you meet yourself, only one of you may return.

## Run it

```sh
python3 main.py
```

The program reads `$MAKEFUN_OUTPUT_DIR` (falling back to `/output`), validates the line against the gate (UTF-8, 1–120 characters, a single line, not whitespace-only, no trailing newline), writes it atomically via a `mkstemp` temp file with a full write loop and fsync, and verifies the written bytes by reading them back.
